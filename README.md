My non-profit desperately needed a website to showcase our work, share information about our events, and keep our audience updated on what we are doing. I decided to teach myself some HTML and CSS to create this website.

The website includes several different pages, including Home, About, Calendar, Contact, and Resources. There is also a Meet the Founder button for visitors who want to learn more about the person behind ReFine.

The Resources page is connected to our Google Drive, where we have made our educational materials freely available. This includes videos, slideshows, and other resources created during our bootcamps and courses.

Features
Home page introducing ReFine
About page with information about the organization
Calendar for upcoming events
Contact page
Resources page with free educational materials
Meet the Founder section
Navigation bar for easy access to different pages
Mobile-friendly menu button for navigation
